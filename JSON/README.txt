현장 파일 위치

JSON/site-directory.json

이 파일은 모든 점검자가 비밀번호 없이 자동으로 읽는 공용 현장 목록입니다.
점검자 이름, 개인 점검표, 사진은 포함하지 않습니다.

변경 방법:
1. 앱 설정에서 관리자 로그인 후 현장 정보를 수정합니다.
2. GitHub용 현장 파일 만들기에서 site-directory.json을 받습니다.
3. GitHub 저장소의 JSON 폴더 안에 덮어 올립니다.
4. 다음 앱 실행 또는 화면 복귀 시 새 목록을 받습니다.

소스 프로젝트 위치: public/JSON/site-directory.json
기존 암호화 파일은 새 파일이 없을 때 호환 경로로 읽습니다.
