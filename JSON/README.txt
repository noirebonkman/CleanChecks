현장 파일 위치

이 폴더의 site-directory.enc.json이 기본 현장 목록입니다.
원본 엑셀이나 복호화 비밀번호를 GitHub에 올리지 마세요.

현장 변경 방법:
1. 앱 설정에서 관리자 로그인 후 현장 정보를 수정합니다.
2. 'GitHub용 암호화 현장 파일 만들기'를 선택합니다.
3. 받은 site-directory.enc.json을 이 폴더에 덮어 올립니다.
4. 같은 파일 비밀번호를 유지하면 직원 기기에서 다음 실행 시 갱신됩니다.

GitHub 저장소: JSON/site-directory.enc.json
소스 프로젝트: public/JSON/site-directory.enc.json

JSON 폴더에 파일이 없으면 이전 data 폴더와 루트 위치 파일도 읽습니다.
기존 현장 파일을 이미 사용 중이면 그 파일을 이 폴더로 옮겨 사용하세요.
현장 파일에는 개인 점검표·사진·점검자 이름이 포함되지 않습니다.
